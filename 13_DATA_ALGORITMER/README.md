# 13. Data og algoritmer

Når et projekt har **mange ens ting** — scores, spillere, kort, spørgsmål — stopper det med at være “ét tal ad gangen”.  
Så arbejder vi med **lister og objekter**, og med små **algoritmer**: søg, filtrer, sorter, find den bedste.

Bygger videre på arrays fra 1. år og på dit personlige API (fx toast, score-hjælpere).

---

## Hvad træner vi her?

- Arrays og objekter som data
- Søge og filtrere i en liste
- Sortere / rangere (fx highscore)
- Genbruge logikken i synlige produkter — ikke “algoritme for algoritmens skyld”

---

## Elevopgave (idé)

Lav et lille **data-drevet produkt**, hvor brugeren kan se og arbejde med en liste.

Vælg selv tema, fx:

- **Leaderboard** — gem scores, sortér efter point, vis top 5
- **Samling** — film, spil, Pokémon, playlist: søg og filtrer
- **Match / ranking** — giv ting point og find “bedste match”

**Minimum:** data i array/objekter, mindst én søgning eller filtrering, mindst én sortering eller ranking, synlig UI der opdateres når data ændres.
